# Development

## WebAssembly dependency

Character data is parsed by the `character` Go library, consumed here as a WebAssembly module (`character.wasm` + `wasm_exec.js`) rather than reimplemented. That module is not part of this repo's source: it's fetched from `character`'s GitHub releases into `public/wasm/`, which stays gitignored.

Fetch a pinned version with:

```sh
npm run wasm:download -- <version>
# e.g.
npm run wasm:download -- v0.8.0
```

Implementation: `scripts/download-wasm.mjs`. It downloads both `character.wasm` and `wasm_exec.js` from `https://github.com/openkakutou/character/releases/download/<version>/`, writing each atomically (temp file + rename) so a failed run never leaves a truncated file in `public/wasm/`. If either asset fails to download, any asset already fetched during that same run is rolled back too — a run either fully updates `public/wasm/` or leaves it exactly as it was.

Run `npm run wasm:download` with no argument, or `-- --help`, to see usage and exit codes:

| Exit code | Meaning |
|---|---|
| `0` | success |
| `2` | usage error — no version argument given |
| `3` | the version tag or one of its release assets was not found |
| `5` | network error, or an unexpected/empty response |

## Running tests

`npm test` runs the full Vitest suite, including `scripts/download-wasm.test.mjs`, which exercises the download logic against an injected fake `fetch` — no real network access is needed to run the test suite.
