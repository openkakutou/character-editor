# UX audit — 2026-10-08

- **Scope:** full UI (`src/`, tests excluded)
- **Captures:** `.ux/captures/audit-2026-10-08/` (home, wizard, loaded character full page, 390 px width). Reused from the baseline taken the same day.
- **Agents run:** review-states, review-accessibility, review-content, review-consistency, review-visual (no conformance: no specs yet). Agents read code by targeted grep; not every file was read in full.

## Summary

Findings: 23 (High: 9, Medium: 8, Low: 6)

The dominant problem is structural: eight editors are stacked on one 2935 px page with the shortcuts panel above them, no navigation and no consistent section styling, which hurts every user on every session. Second, several async paths (export, wizard, folder load, sprite and animation previews) can stay stuck on "Loading…" forever, which blocks the task. Third, French users meet English in the file pickers, the shortcut labels and raw error messages, and keyboard users cannot resize collision boxes.
