# Module: shortcuts
**Role:** The keyboard-shortcut layer (item 011), built on `@openkakutou/web-ui-kit`'s `ShortcutManager`/`<wuik-shortcuts-panel>` rather than a hardcoded key handler. `app-shortcuts.ts` registers this app's fixed set of six actions (`undo`, `redo`, `download-all`, `add-animation`, `add-statedef`, `add-command`) on a shared singleton manager, each id equal to the `data-action` attribute already present on the one button that performs it — these action labels stay hardcoded English (item 012), since `ShortcutManager`/`<wuik-shortcuts-panel>` has no supported way to update a registered action's label after the fact. `global-shortcut-listener.ts` installs one `window` `keydown` listener, once at bootstrap, that resolves the pressed combo and calls `.click()` on the matching `data-action` button — no action logic is duplicated. `shortcuts-screen.ts` mounts the shared `<wuik-shortcuts-panel>` (which retranslates its own text internally, via `web-ui-kit`'s own i18n layer) as an always-visible screen, not gated behind a loaded character; its own "Keyboard shortcuts" heading is read through `i18n.t()` and retranslated in place via its own `onLocaleChange` subscription.
**Files:** `src/shortcuts/app-shortcuts.ts`, `src/shortcuts/global-shortcut-listener.ts`, `src/shortcuts/shortcuts-screen.ts`
**Exports:** `APP_SHORTCUT_ACTIONS: readonly ShortcutAction[]`, `registerAppShortcutActions(manager): void`, `getAppShortcuts(): ShortcutManager`, `resetAppShortcutsForTests(): void`, `normalizeShortcutEvent(event): string | undefined`, `shouldIgnoreGlobalShortcut(target): boolean`, `installGlobalShortcutListener(options?): () => void`, `renderShortcutsScreen(root, options?): void`
**Depends on:** `@openkakutou/web-ui-kit` (external — `ShortcutManager`, `<wuik-shortcuts-panel>`), `modules/app.md` (the `data-action` buttons it clicks through), `modules/i18n.md`
