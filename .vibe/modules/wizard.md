# Module: wizard
**Role:** The new-character wizard (backlog item 010): creates a minimal character from scratch — a blank template, or a "basic" template pre-populated with one starting animation and StateDef — as an alternative to importing one. `new-character-wizard.ts` is the DOM-free logic: builds the template's `CharacterInfoFields`/`Animation[]`/`StateDef[]`/`CommandFile`, serializes them via the `character` WASM module's `saveDef`/`saveAir`/`saveCns`/`saveCmd` calls with an empty `Uint8Array` as each "original bytes" argument (a case those calls already support for a brand-new character), pairs the result with a bundled placeholder `.sff` (`public/wizard/blank-character.sff`, committed — there is no `sff` WASM encode path, `.vibe/decisions/013`), and round-trips the whole thing back through `wasm.loadCharacter` so the result is provably loadable, not just assumed so. Never throws: any step's failure (including fetching the bundled `.sff`) is caught and reported as the same typed `CharacterInputResult` the file input uses. `new-character-wizard-view.ts` is the dialog UI (template radio choice, Name field, inline validation) — visibility is driven by the `open` attribute directly, never `.showModal()`/`.close()`, so it behaves the same whether or not the real `web-ui-kit` custom elements are registered.
**Files:** `src/wizard/new-character-wizard.ts`, `src/wizard/new-character-wizard-view.ts`
**Exports:** `WizardTemplate`, `CreateCharacterOptions`, `buildCharacterInfo(name): CharacterInfoFields`, `buildAnimations(template): Animation[]`, `buildStateDefs(template): StateDef[]`, `createCharacterFromWizard(name, template, options?): Promise<CharacterInputResult>` (new-character-wizard.ts); `NewCharacterWizardOptions`, `renderNewCharacterWizard(root, options): void` (new-character-wizard-view.ts)
**Depends on:** `modules/wasm.md` (`saveDef`/`saveAir`/`saveCns`/`saveCmd`/`loadCharacter`), `modules/input.md` (`CharacterInputResult`/`LoadedFileBytes`, the same result shape the file input produces), `modules/commands.md` (reuses `emptyCommandFile`)
