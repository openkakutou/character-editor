# Module: wasm
**Role:** Bridge to the `character` WebAssembly module — loads it client-side and exposes typed wrappers around `OpenKakutouCharacter.load` (`loadCharacter`), `resolveSprites` (`resolveSpritePixels`, item 004's sprite pixel decoding), `loadCmd` (`loadCmd`, item 008: parses a `.cmd` file's bytes into a typed `CommandFile`, since `.cmd` isn't wired into `load`'s own JSON contract), and `saveDef`/`saveAir`/`saveCns`/`saveCmd` (item 009: serialize `.def`/`.air`/`.cns`/`.cmd` bytes for the current in-memory data, byte-exact to the original when unmodified).
**Files:** `src/wasm/bridge.ts`, `src/wasm/types.ts`
**Exports:** `loadCharacter(defBytes, airBytes, sffBytes, cnsBytes, options?): Promise<CharacterResult>`, `resolveSpritePixels(sffBytes, requests, overridePaletteBytes, options?): Promise<SpritePixelResult[]>`, `loadCmd(cmdBytes, options?): Promise<LoadCmdResult>`, `saveDef(originalDefBytes, info, options?): Promise<SaveResult>`, `saveAir(originalAirBytes, animations, options?): Promise<SaveResult>`, `saveCns(originalCnsBytes, stateDefs, options?): Promise<SaveResult>`, `saveCmd(originalCmdBytes, commandFile, options?): Promise<SaveResult>`, `resetWasmBridgeForTests(): void`, `WasmBridgeOptions`, `SaveResult`, `CharacterData`, `CharacterInfoFields`, `CharacterResult`, `SpritePixelResult`, `LoadCmdResult`, `Animation`, `Frame`, `ClsnBox`, `Sprite`, `SpriteGroup`, `Controller`, `StateDef`, `CommandFile`, `Command`, `CommandDefaults`
**Depends on:** the `character.wasm` + `wasm_exec.js` build fetched into `public/wasm/` (gitignored, via `scripts/download-wasm.mjs`)
