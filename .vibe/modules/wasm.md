# Module: wasm
**Role:** Bridge to the `character` WebAssembly module — loads it client-side and exposes typed wrappers around `OpenKakutouCharacter.load` (`loadCharacter`), `resolveSprites` (`resolveSpritePixels`, item 004's sprite pixel decoding), `loadCmd` (`loadCmd`, item 008: parses a `.cmd` file's bytes into a typed `CommandFile`, since `.cmd` isn't wired into `load`'s own JSON contract), and `saveDef`/`saveAir`/`saveCns`/`saveCmd` (item 009: serialize `.def`/`.air`/`.cns`/`.cmd` bytes for the current in-memory data, byte-exact to the original when unmodified).
**Files:** `src/wasm/bridge.ts`, `src/wasm/types.ts`, `src/wasm/snd-bridge.ts`
**Exports:** `loadCharacter(defBytes, airBytes, sffBytes, cnsBytes, options?): Promise<CharacterResult>`, `resolveSpritePixels(sffBytes, requests, overridePaletteBytes, options?): Promise<SpritePixelResult[]>`, `loadCmd(cmdBytes, options?): Promise<LoadCmdResult>`, `saveDef(originalDefBytes, info, options?): Promise<SaveResult>`, `saveAir(originalAirBytes, animations, options?): Promise<SaveResult>`, `saveCns(originalCnsBytes, stateDefs, options?): Promise<SaveResult>`, `saveCmd(originalCmdBytes, commandFile, options?): Promise<SaveResult>`, `resetWasmBridgeForTests(): void`, `WasmBridgeOptions`, `SaveResult`, `CharacterData`, `CharacterInfoFields`, `CharacterResult`, `SpritePixelResult`, `LoadCmdResult`, `Animation`, `Frame`, `ClsnBox`, `Sprite`, `SpriteGroup`, `Controller`, `StateDef`, `CommandFile`, `Command`, `CommandDefaults`; `applySndEdits`, `decodeSndSound`, `resetSndBridgeForTests`, `SndEdit`, `SndBridgeOptions`, `SndBytesResult`, `SndSoundResult`
**Depends on:** the `character.wasm` + `wasm_exec.js` build fetched into `public/wasm/` (gitignored, via `scripts/download-wasm.mjs`); `public/wasm/snd/` (`snd.wasm` + its own `wasm_exec.js`, gitignored)

**Sounds (item 017):** `loadCharacter` accepts `options.sndBytes` (the WASM `load`'s optional fifth argument); `CharacterData.sounds?: SoundGroup[]` (`Sound`: group, sample, sampleRate, channels, bitsPerSample, pcm, optional `error` for an entry that failed to decode). Requires `character` WASM >= v0.10.0 for per-sound errors.

`warmUpEngine(options)` starts or joins the one memoized instantiation (a failed attempt is forgotten, so Retry tries again).

**`snd` bridge (item 023):** `src/wasm/snd-bridge.ts` loads `snd.wasm` and its own `wasm_exec.js` from `public/wasm/snd/` (a separate Go runtime from `character`'s) and wraps `OpenKakutouSnd`: `applySndEdits(sndBytes, edits)` replays add/replace/delete edits in order and stops at the module's first refusal, `decodeSndSound(sndBytes, group, sample)` returns the editor's `Sound` shape. Memoized like the `character` bridge; `resetSndBridgeForTests`.
