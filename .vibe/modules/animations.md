# Module: animations
**Role:** The animation editor (backlog item 006): create/edit `.air` animations — add/remove/reorder Frames, edit each Frame's sprite reference and duration, add/drag/resize/delete Clsn1/Clsn2 boxes per frame with a live preview overlay slotted inside `web-ui-kit`'s `<wuik-viewport>`, and a play/pause/step playback preview. Clsn boxes are editable three equivalent ways (numeric x/y/width/height, arrow-key nudge, pointer drag), every committed coordinate snapped to an integer pixel — see `.vibe/decisions/007-animation-editor-clsn-interaction-model.md`.
**Files:** `src/animations/animation-logic.ts`, `src/animations/animation-playback.ts`, `src/animations/animation-editor.ts`
**Exports:** `nextAnimationNumber(animations)`, `newAnimation(number)`, `newFrame()`, `newClsnBox()`, `moveClsnBox(box, dx, dy)`, `resizeClsnBox(box, handle, dx, dy)`, `setClsnBoxBounds(x, y, width, height)`, `spriteReferenceExists(spriteGroups, group, image)`, `ClsnResizeHandle` (animation-logic.ts) — DOM-free pure logic; `advanceFrame(frames, currentIndex, loopStart)`, `stepFrame(frames, currentIndex)`, `shouldAutoAdvance(frames, index)`, `PlaybackAdvanceResult` (animation-playback.ts) — DOM/timer-free playback logic; `renderAnimationEditor(root, character, sffBytes, spriteEdits, options): void`, `AnimationEditorOptions`, `PlaybackTimer`, `defaultDrawPixels` (animation-editor.ts) — the DOM layer
**Depends on:** `modules/wasm.md` (`resolveSpritePixels`, `CharacterData`/`Animation`/`Frame`/`ClsnBox`), `modules/sprites.md` (`mergeSpriteGroups`/`spriteEditFor`/`SpriteEdit`, so a frame's sprite reference is checked against the sprite browser's own pending edits, not just WASM-parsed metadata), `@openkakutou/web-ui-kit` (`<wuik-viewport>`, `<wuik-button>`)
