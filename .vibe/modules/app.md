# Module: app
**Role:** Application entry point — mounts the app into the DOM as a `web-ui-kit` app shell (toolbar with title/version and a light/dark theme toggle, the character file input, the characteristics editor, the sprite browser, the palette editor, the state editor, the animation editor, the command editor, and the export panel once a character loads), or a clear error state when the installed `web-ui-kit` version is too old. Re-renders the animation editor on every sprite-browser edit (not just once at load) so its sprite-existence checks and live Clsn preview stay current against the sprite browser's own pending edit overlay — reading the document store's latest character each time rather than the `onLoaded` closure's now-stale one. The export panel, by contrast, is rendered once here and recomputes itself on its own explicit action rather than being re-rendered from here — see `.vibe/decisions/010`.
**Files:** `src/main.ts`, `src/version.ts`, `src/web-ui-kit-version.ts`, `src/style.css`, `src/types/web-ui-kit.d.ts`
**Exports:** `appVersion: string`, `renderApp(root, version, installedWebUiKitVersion, options?): void`, `RenderAppOptions`, `MIN_SUPPORTED_WEB_UI_KIT_VERSION: string`, `isWebUiKitVersionSupported(version): boolean`
**Depends on:** `@openkakutou/web-ui-kit` (external — layout shell, tokens, button/viewport components), `modules/input.md`, `modules/document.md`, `modules/editors.md`, `modules/sprites.md`, `modules/palettes.md`, `modules/animations.md`, `modules/commands.md`, `modules/save.md`
