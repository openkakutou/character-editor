# Module: app
**Role:** Application entry point — mounts the app into the DOM as a `web-ui-kit` app shell (toolbar with title/version, an unsaved-changes indicator, Undo/Redo buttons, and a light/dark theme toggle; the character file input, the new-character wizard trigger, the characteristics editor, the sprite browser, the palette editor, the state editor, the animation editor, the command editor, and the export panel once a character loads), or a clear error state when the installed `web-ui-kit` version is too old. Re-renders the characteristics editor, sprite browser, state editor, and animation editor on every sprite-browser/characteristics/state edit and on every Undo/Redo click (`onHistoryChange`) so their state stays current against the document store's latest character — reading it fresh each time rather than a stale closure. Three screens are deliberately excluded from that Undo/Redo re-render: the palette editor (manages its own undo/redo via a returned `PaletteEditorHandle.refresh()` plus an `onHistoryPush` callback that keeps the toolbar in sync, see `modules/palettes.md`), the export panel (recomputes only on its own explicit action, `.vibe/decisions/010`), and the command editor (mounted exactly once at initial load, never again — see `modules/commands.md` and `.vibe/decisions/011`). The file input and the wizard are two alternative entry points into the same "character loaded" handler, wired identically. Installs the `beforeunload` unsaved-changes guard once at bootstrap.
**Files:** `src/main.ts`, `src/version.ts`, `src/web-ui-kit-version.ts`, `src/style.css`, `src/types/web-ui-kit.d.ts`
**Exports:** `appVersion: string`, `renderApp(root, version, installedWebUiKitVersion, options?): void`, `RenderAppOptions`, `MIN_SUPPORTED_WEB_UI_KIT_VERSION: string`, `isWebUiKitVersionSupported(version): boolean`
